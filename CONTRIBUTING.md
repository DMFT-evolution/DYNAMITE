# Contributing to DYNAMITE

Contributions are welcome. For larger changes, please open an issue first. Pull requests should be focused on one change, state how it was tested, and update the documentation in `docs/` where the behaviour visible to users changes.

Conventions, the regression tests (`tests/run_regression.py`) and how to build the documentation are described on the [Development](https://dmft-evolution.github.io/DYNAMITE/dev/development/) page.
